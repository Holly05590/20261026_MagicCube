# 魔術方塊學習筆記

繁體中文 3×3 OLL 57 學習網站，適合電腦與手機使用。純 HTML、CSS、JavaScript，不需要安裝套件、編譯或後端服務。

## 如何先在電腦看

解壓縮專案後，直接開啟 `index.html`。所有本機檔案請保持原有位置。進入「讀圖與轉動說明」，即可操作轉動動畫。

## 自己上傳到 GitHub Pages

1. 在 GitHub 建立儲存庫，例如 `cube-learning`。使用 GitHub Free 時，可建立公開儲存庫。
2. 在儲存庫按 **Add file → Upload files**。
3. 上傳本資料夾「裡面」的檔案與 `assets` 資料夾，讓 `index.html` 位於儲存庫最外層。不要只上傳 ZIP，也不要把整個專案多包一層資料夾。
4. 按 **Commit changes** 儲存。
5. 開啟 **Settings → Pages**，在 **Source** 選 **Deploy from a branch**。
6. 選擇檔案所在分支（通常是 `main`），資料夾選 **/(root)**，再按 **Save**。
7. 等待發布完成，回到 Pages 頁面取得網址。一般專案網址形式為 `https://你的帳號.github.io/儲存庫名稱/`；以 GitHub 實際顯示的網址為準。
8. 用手機開啟該網址，亦可用手機瀏覽器的「加入主畫面」功能建立捷徑。

`.nojekyll` 是空白設定檔。如果拖曳上傳時沒有帶入，可在儲存庫用 **Add file → Create new file** 建立名為 `.nojekyll` 的檔案。此專案也沒有需要 Jekyll 處理的檔案。

操作依 GitHub 官方說明整理（2026-10-26）：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 網站包含什麼

- 57 個 OLL 編號、15 個分類、頂面及四側黃色貼紙辨識圖。
- 英文公式、中文箭頭口訣、逆公式製造練習場景。
- 說明頁內建動畫：R/L/U/D/F/B；r/l/f；M/E/S；x/y/z，均可選順轉、逆轉、半圈。
- 57 個 OLL 公式的逐步及連續動畫，完整對應 30 天計畫。
- 30 天計畫、隨機抽題、遮住公式、自訂勾選與進度 JSON 匯入／匯出。

## 教孩子時怎麼用

先在說明頁選「單一符號」與「固定看前、右、上」，練習 R、R′、R2、U、U′。動畫現在一律固定看前、右、上；L、B、D 的順逆仍以正對該面判斷。最後選「27 小魚，逐步練習」，每按一次下一步，跟著實體方塊轉一次。

順逆時針以「正對正在轉的面」為準。動畫上的字母與數字追蹤原始貼紙位置，並非實體方塊要額外貼上的標記。改變觀察視角不等於公式中的整顆換握。

## 進度與離線使用

- 練習進度保存在目前裝置、目前瀏覽器及網站來源的 localStorage，沒有帳號或雲端同步。
- 不同手機、不同瀏覽器、無痕模式、清除網站資料或改用另一個網址，可能無法讀取原進度；請定期匯出 JSON 備份。
- 從本機檔案改到網站時，先從原筆記匯出進度，再到網站匯入。
- 專案沒有追蹤程式，沒有將勾選資料上傳的程式。託管平台本身仍可能記錄一般網站存取資訊。
- 下載完整專案後可本機離線使用。線上網站沒有 service worker；「加入主畫面」是捷徑，不保證斷網後仍可開啟。

## 檔案結構

- `index.html`：網站入口、頁面骨架、動畫範本。
- `assets/styles.css`：手機與電腦排版、圖形樣式。
- `assets/app.js`：57 案例資料、公式圖、計畫及進度功能。
- `assets/animation.js`：三維貼紙模型與動畫。
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔案。
- `VALIDATION.md`：驗證項目與限制。

## 完整 30 天操作方式

- 點「30 天學習計畫」，用左側日期選單回到任一天；手機會把日期選單排在上方。
- 第 1～28 天：選當天的 OLL 編號，查看對應圖形、公式、中文口訣與動畫。28 天共涵蓋 57 例，第 28 天有 3 例。
- 第 29 天：依分類總複習，選擇分類與案例，全部 57 例都能直接播放動畫。
- 第 30 天：隨機且不重複的 57 題混合驗收，分三輪、每輪 19 題。可選上一題、下一題或重新抽題。抽題順序僅在此次開啟頁面期間保留，重新載入會重新抽題。
- 「下一步」轉一次；「連續播放」從目前步驟播到結束；播放中可暫停，完成當前轉動後停下，再次按連續播放即可接續。
- 「從頭練習」回到該案例起始場景。完整播放結束後再按連續播放，會自動重頭開始。
- 所有動畫固定看前、右、上。日期及公式切換會停止上一個動畫。
- 原本的會辨識、能默背、已熟練與每日完成勾選仍保留；觀看動畫不會自動替孩子勾選完成。
- 更新網站時，請一併上傳 index.html 與整個 assets 資料夾。

## 還原場景動畫

每個公式的「動畫版本」可切換：

- 解題動畫：從該題場景開始，執行 OLL 解法，完成後頂面全黃。
- 還原場景：從完全復原的方塊開始，執行該解法的逆公式，製造與辨識圖相同的練習場景。

兩種均支援下一步、連續播放／暫停與從頭練習。切換版本會回到該版本起始狀態，不會沿用轉到一半的方塊。還原場景是準備練習題目，結束時頂面通常不會全黃。第 1～30 天的案例及說明頁的小魚示範皆可使用；單一符號模式維持原本的符號教學。
